# Sea Level Predictor

Predicts global sea level rise through 2050 using historical data from 1880 to present.

## Features

- **Scatter Plot**: Shows historical sea level measurements.
- **Line of Best Fit (All Years)**: Predicts rise through 2050.
- **Line of Best Fit (2000 Onwards)**: Shows recent trend and predicts rise through 2050.

## Technologies

- Python
- Pandas
- Matplotlib
- SciPy

## Usage

1. Ensure `epa-sea-level.csv` is in the project folder.
2. Install required packages:

pip install pandas matplotlib scipy

Run the main script:

python main.py

The plot will be saved as sea_level_plot.png.
